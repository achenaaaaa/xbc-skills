# 秋招岗位分析与适配 Skill

协助用户完成秋招求职全流程：公司深度背调 → 岗位适配度评分 → 投递策略与笔面试准备。

## 前置步骤：获取用户简历

在开始任何分析之前，检查上下文中是否已有用户简历信息。如果没有，从 `references/resume.md` 读取。若该文件也为空，主动向用户索要简历（PDF 路径或文字描述）。

## 模块一：目标公司深度分析

当用户指目标公司或从岗位 JD 中提取公司名称后，执行以下四个维度的分析：

### 1.1 行业地位与竞争格局

通过 WebSearch 搜索以下信息：
- 公司在所处行业的市场份额与排名
- 主要竞争对手及竞争优劣势对比
- 公司是否为央企/国企/上市公司，及其在集团/行业内的层级
- 近年重大战略动作（并购、业务线调整、新市场进入等）

### 1.2 财务健康度

对于上市公司，搜索最近 1-3 年的关键财务指标：
- 营收与净利润规模及增速
- ROE、毛利率、净利率趋势
- 资产负债率与现金流状况
- 机构评级与研报观点摘要

对于非上市公司，搜索注册资本、融资轮次、股东背景等替代信息。

输出时标注信息来源和时效性。

### 1.3 发展战略与风险

- 公司十四五/十五五战略规划要点
- 新业务/新赛道布局方向
- 近期舆情、监管处罚、经营风险事件
- 行业政策对公司的影响判断

### 1.4 社交平台评价（多平台）

从以下 6 个国内主流平台搜索目标公司的真实评价，逐平台搜索、逐平台汇总：

| 平台 | 搜索策略 | 关注重点 |
|------|---------|---------|
| **小红书** | `{公司名} 工作 待遇 评价 怎么样` | 员工晒薪、工作氛围、加班情况 |
| **知乎** | `{公司名} 怎么样 值得去吗` | 长篇深度评价、行业内人士回答 |
| **微博** | `{公司名} 秋招 裁员 待遇` | 热点舆情、负面事件、工资讨论 |
| **抖音** | `{公司名} 工作 vlog 待遇` | 职场博主视频、办公环境实拍 |
| **快手** | `{公司名} 工作 日常` | 员工工作日常、工厂/办公环境 |
| **百度贴吧** | `{公司名}吧 site:tieba.baidu.com` | 校招讨论帖、offer 对比、内部消息 |

每个平台搜索结果需：
- 总结该平台的主流评价倾向（正面/负面/中性比例）
- 摘录 2-3 条有代表性的评价原文或摘要
- 标注搜索日期与平台来源

汇总时综合评估各平台舆论风向，给出"公司口碑健康度"总体判断。

### 分析输出格式

```
## {公司名称} 深度分析

### 行业地位
...（含来源）

### 财务健康度
...（含来源与时效）

### 发展战略与风险
...（含来源）

### 社交平台评价

| 平台 | 倾向 | 代表性评价 |
|------|------|-----------|
| 小红书 | 正面/中性/负面 | ... |
| 知乎 | ... | ... |
| ... | ... | ... |

**口碑总评**: ...

*数据来源: WebSearch, 搜索日期: {日期}*
```

## 模块二：岗位适配度匹配

### 2.1 JD 关键要素提取

从用户提供的岗位描述中提取：
- 学历与专业要求
- 核心技能要求（硬技能/软技能）
- 经验要求（实习/项目/证书）
- 加分项与偏好（政治面貌、籍贯、行业背景等）
- 岗位所属层级（省公司/市公司/支公司/总部）

### 2.2 简历逐项对比评分

将 JD 要求与用户简历逐项对比，生成匹配度评分表：

```
## 岗位适配度分析：{岗位名称}

### 匹配度总评：{百分比}

| 维度 | 要求 | 你的情况 | 匹配 |
|------|------|---------|------|
| 学历 | ... | ... | ✅/⚠️/❌ |
| 专业 | ... | ... | ✅/⚠️/❌ |
| 核心技能 | ... | ... | ✅/⚠️/❌ |
| 经验 | ... | ... | ✅/⚠️/❌ |
| 加分项 | ... | ... | ✅/⚠️/❌ |
```

### 2.3 差距分析与弥补建议

- 标注 ⚠️ 和 ❌ 项的差距程度
- 对可弥补的差距给出具体建议（简历措辞调整、技能快速补学、经验替代展示等）
- 对硬性门槛差距如实告知

### 2.4 往年招聘参考

搜索该公司或同类岗位近 1-3 年的校招录取信息，汇总以下维度：

- 录取人员的学历层次分布（博士/硕士/本科比例）
- 录取人员的院校层次分布（985/211/双非/海归等）
- 录取人员的专业背景分布
- 竞争比（报名人数/录取人数，若有）
- 笔试/面试通过率参考（若有）
- 往年该岗位或类似岗位的录取人数

搜索策略：
- 优先搜索官方公示（拟录用名单、校招结果公告）
- 其次搜索第三方汇总（应届生论坛、牛客网、知乎 offer 帖）
- 搜索关键词：`{公司名} 校招 录用 名单 学历` `{公司名} 秋招 offer 背景` `{公司名} 202X届 校招 录取`

输出格式：
```
### 往年招聘参考

| 维度 | 数据 |
|------|------|
| 学历分布 | ... |
| 院校层次 | ... |
| ... | ... |

*数据来源/说明：...*
```

若无法找到相关信息，如实说明搜索范围和缺失原因（如"该公司未公示录用名单""搜索平台未找到相关讨论"），避免虚构数据。

### 2.5 简历针对性优化

提供 2-3 处具体、可用于该岗位的简历措辞修改建议（控制在 200 字以内）。

## 模块三：投递策略与备考

### 3.1 志愿排序建议

根据用户偏好（如：优先省公司、地域倾向）和岗位竞争度，给出 2 个阶梯志愿的推荐组合，说明理由。

### 3.2 笔试备考

- 笔试类型判断（综合类/科技类/行测+专业）
- 各板块备考重点与时间分配建议
- 推荐刷题方向

### 3.3 面试准备

- 基于岗位职责预测 5 个高频面试问题
- 结合用户简历给出回答要点提示
- 如为管培岗，提示无领导小组讨论的常见议题方向

### 3.4 薪资与福利参考

搜索该岗位或同类公司的应届生薪资范围（标注来源）。

## 使用示例

1. **完整分析**: "帮我分析人保财险湖南省分公司中后台管理岗" → 执行全部三个模块
2. **仅公司分析**: "帮我看看中国人保这家公司怎么样" → 仅执行模块一
3. **仅岗位匹配**: "帮我看看这个 JD 适合我吗" + 粘贴岗位描述 → 执行模块二和三
4. **多岗位对比**: "帮我比较人保湖南中后台岗和广东管培岗" → 对每个岗位执行模块二，横向对比

## 注意事项

- 所有 WebSearch 来源需标注搜索日期和来源平台
- 社交平台评价需如实反映正负面比例，不刻意美化
- 对硬性门槛差距（如学历不达标）需如实告知，不鼓励盲目投递
- 遵循用户"优先省公司、不选本级（总部）"的默认偏好，除非用户另有指示
