# 经济学文献综述写作工作流

> 完整流程：分析缺口 → 搜索文献 → 下载PDF → 核验内容 → 撰写综述

## 触发条件

当用户需要为经济学实证论文撰写或补充文献综述时触发。典型触发词：文献综述、literature review、补充引用、找文献、文献整理。

## 前置条件

- 已了解论文的研究主题、核心变量、研究设计
- 已明确需要覆盖的文献线（如"关键核心技术创新"、"供应链风险"等）

## 完整工作流

### 步骤 1：分析文献缺口

阅读用户论文引言部分，识别：
- 已有文献覆盖了哪些主题线
- **缺失了哪些主题线**（如引言只写了供应链风险文献，缺乏核心技术文献）
- 需要补充的具体方向（概念界定、测度方法、驱动因素等）

### 步骤 2：按主题分层搜索文献

**搜索策略**：对每个需要的子主题分别搜索，优先中文顶级期刊（经济研究 > 中国工业经济 > 管理世界 > 经济学季刊 > 证券市场导报等），辅以英文顶刊。

**搜索关键词模板**：
```
{核心主题} {子主题} {中文顶刊列表} {年份范围}
```

**示例**：
```
"关键核心技术" 企业创新 概念 定义 测度 经济研究 中国工业经济 2020 2021 2022 2023
```

### 步骤 3：按优先级分级文献

将搜索结果分为三级：

| 级别 | 标准 | 行动 |
|------|------|------|
| **P0** | 标题、主题、期刊均高度匹配，必须引用 | 优先下载 |
| **P1** | 主题相关，期刊略低或方向偏，可作为支撑 | 次优下载 |
| **P2** | 关联较弱，仅做备选 | 最后下载或放弃 |

### 步骤 4：创建下载目录并下载 PDF

**目录命名**：`下载到用户指定的路径/{论文主题}_文献综述`

**下载方法**：使用 `curl -L -o` 命令下载 PDF。

**常见下载失败原因**：
- 标题不完整（缺少副标题）→ 用完整标题重新搜索
- 知网/万方需要机构权限 → 告知用户手动下载
- PDF 链接过期 → 搜索其他镜像源

### 步骤 5：提取 PDF 内容并逐篇核验

**提取方法**：使用 Python + PyPDF2 批量提取 PDF 文本。

```python
from PyPDF2 import PdfReader
reader = PdfReader(pdf_path)
for page in reader.pages:
    text = page.extract_text()
    # 保存到提取文本文件
```

**核验清单（每篇必检）**：
- [ ] 标题与作者是否一致
- [ ] 期刊名、卷号、期号、页码是否准确
- [ ] 核心发现（被解释变量 + 解释变量 + 方向 + 显著性）
- [ ] 机制分析（中介变量 + 路径）
- [ ] 异质性分析（分组依据 + 结果差异）
- [ ] 与用户论文的关系（可引用点）

**仅引用已成功下载并核验内容的文献。** 未能下载的文献记录到"待下载清单"表格，不引用其内容。若文献真实但下载失败，告知用户手动下载后继续。

### 步骤 6：按逻辑线组织并撰写综述

**组织原则**：按主题维度而非时间顺序排列，最后收束到研究缺口。

**标准结构**：

```
[段落1] 概念界定：不同学者对该概念的几类定义视角
  ↓
[段落2] 测度方法：主流的几种测度/识别方案
  ↓
[段落3-N] 驱动因素：按维度分条线
  ├── 外部政策维度
  ├── 融资与资本维度
  ├── 数字化转型维度
  └── ...（其他相关维度）
  ↓
[末尾] 研究缺口 → 本文边际贡献
```

**写作要求**：
- 每段 300-500 字，简明扼要
- 使用"X 等（年份）发现……"的统一句式
- 不做文献的简单堆砌，每篇文献只需 1-2 句核心信息
- 段与段之间用逻辑连接词衔接（"在……方面""进一步地""然而"）
- 最后一句明确点出研究缺口

### 步骤 7：输出

**输出文件**：
1. `文献综述_{主题}.md` — 完整综述正文
2. 引用文献清单表格（含核验状态）
3. 待手动下载的文献清单（如有）

**引用格式**：作者, 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.

### 步骤 8：核对重复文献并统一引用格式

综述撰写完成后，必须与用户论文的已有参考文献列表进行交叉核对，避免重复引用或引用格式不一致。

**8.1 获取已有文献列表**

要求用户提供论文中已有的全部参考文献列表（中文文献即可）。通常格式为：

```
[1] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
[2] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
...
```

**8.2 逐条核对重复情况**

对于综述中引用的每一篇文献，逐一检查是否已存在于用户文献列表中：

| 核对要点 | 方法 |
|---------|------|
| 作者+年份相同 | 可能是同一篇或同一作者的不同论文 |
| 标题部分重合 | 确认不是同篇论文的不同版本（如工作论文 vs 正式发表） |
| 期刊/卷期一致 | 确认是否为同一篇论文的同一版本 |

**特别注意**：同一作者同一年份可能发表了多篇不同论文（如张杰2018年同时发表了"创新补贴政策的绩效评估"和"创新追赶战略抑制了中国专利质量么"），需确认具体是哪一篇。

**8.3 输出核对结果**

以表格形式呈现：

```
| # | 综述引用的文献 | 已有文献列表 | 结果 |
|---|---------------|-------------|:--:|
| 1 | 作者A (年份) | [X] 同一篇 | ✅ 已有 |
| 2 | 作者B (年份) | — | ❌ 缺失 |
```

**8.4 为新增文献生成统一格式的引用编号**

对于已有文献：直接使用用户文献列表中原有的编号（如"[4]"）。

对于新增文献：按用户文献列表的编号顺序，从最大编号后继续编号（如最大为 [52]，则新增从 [53] 开始）。输出新增文献的标准引用格式：

```
[53] 作者. 标题[J]. 期刊, 年份, 卷(期): 页码.
```

**特别注意**：新增文献列表的编号必须与用户原文中的编号风格完全一致，**不能改变原有编号的顺序和格式**。

**8.5 更新综述正文中的引用编号**

将综述正文中的文献引用从"作者（年份）"格式全部替换为对应的引用编号格式"[X]"。已有文献使用原编号，新增文献使用新编号。

## 注意事项

- ⚠️ **真实性第一**：只引用已成功下载并核验内容的文献
- ⚠️ 不编造引用、不猜测内容
- ⚠️ 如某篇文献无法下载，列清单告知用户，不强行引用
- ⚠️ 经济学论文的文献综述优先引用中文顶刊（经济研究/中国工业经济/管理世界），辅以英文顶刊
